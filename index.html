About the channel / チャンネルについて

If World is a short-video channel that takes a “what if” question — What if social media disappeared? What if mosquitoes vanished? — and shows it as a short simulated video story.

If Worldは、「もしもSNSが使えなくなったら？」「もしも蚊がいなくなったら？」といった“もしも”の問いを、短いシミュレーション動画で描くショート動画チャンネルです。

  • TikTok: @if.world.moshimo
  • YouTube: @if.world.moshimo

About this site / このサイトについて

This site is the information page for If World Draft Uploader, a personal workflow tool used by the creator of If World. The tool's only function is to send the creator's own finished video files to the creator's own TikTok inbox as unpublished drafts, using TikTok's Content Posting API (Upload) with the video.upload scope. It does not publish anything directly — every video is reviewed and posted manually by the creator inside the TikTok app.

このサイトは、If Worldのクリエイター本人が使う作業用ツール「If World Draft Uploader」の案内ページです。このツールの機能は、完成した動画ファイルをクリエイター本人のTikTok受信箱へ未公開の下書きとして送ることだけです。直接公開はせず、投稿は本人がTikTokアプリ内で確認して行います。
